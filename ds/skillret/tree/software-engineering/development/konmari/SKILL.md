# konmari

Repository cleanup skill inspired by Marie Kondo's KonMari Method. Analyzes repos for dead files, unused dependencies, stale docs, orphaned configs, and legacy code. Triggers on cleanup commands like "tidy up", "declutter", or "/konmari".
