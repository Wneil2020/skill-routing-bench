# markdown-writer

Write markdown content to file paths using the MCP markdown-writer server. Use when you need to save generated markdown content to a file, especially in contexts where (1) The Write tool is unavailable or restricted, (2) You need guaranteed atomic writes with verification, (3) Writing markdown files
